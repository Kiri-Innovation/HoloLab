# 首页真实画布截图

首页使用真实产品画布截图，替代原来的 HTML/SVG 示意节点。保留首页分区和站点版式，不复制另一套产品节点组件。

## 来源与可行性

2026-10-13 通过 Playwright 只读访问线上产品。与用户描述最接近的是 `3711480d…` 工作流，当前共 11 个节点，包括 video-array-source、frame-extraction、regroup、get-index、colmap-sfm、colmap-triangulate、image-undistort、merge-colmap、slice、stg-train、stg-to-splatv。当前没有 icp-align，不将其补画进去。

`272b31c3…` 当前是另一条 rig 链，未选用。所选流程是现有实验工作流，不能称作已经过公开审查的 demo；下述脱敏是公开资产生成的一部分。

浏览器直连（取消代理变量并使用 Chromium `--no-proxy-server`），独立上下文，DPR 2。只允许 GET/HEAD/OPTIONS 请求，实际未尝试写请求；没有运行、停止、修改、保存工作流，也没有重启服务。

## 脱敏与取景

| 项目 | 处理 |
| --- | --- |
| 工作流名称、ID、面包屑 | 仅截画布内完整节点链，顶栏不进入截图 |
| 计算节点名称、机器 ID、存储目录 | 左右侧栏、运行历史、底部监控不进入截图；节点标题第二行仅保留版本号 |
| 运行时间 | 在截图用浏览器内隐藏节点 footer 的耗时/相对时间文本，保留进度计数与原有状态 |
| 原始视频、帧缩略图、源文件名 | 在截图用浏览器内隐藏 source、extraction、regroup 的预览抽屉，避免公开实验原始影像；隐藏点云预览中的 frame 文件名标签 |
| 深色中文区域 | 本次实际观察为 stg-train 的“读取中…”产物预览占位；对应产品 `hololab/frontend/src/canvas/PreviewPlaceholder.tsx:105`，不是本次观察到的报错。隐藏该预览抽屉，不伪造成功结果 |
| 节点名、版本、端口、类型、计数 | 保留通用算法标识和技术信息；未出现人名或文件路径 |
| 相机/点云 | 保留三处真实 COLMAP 预览，没有替换模型、坐标轴或渲染结果 |
| 菜单、tooltip、光标、辅助控件 | 鼠标移出画布，隐藏截图不需要的画布控件，没有选中节点或操作右键菜单 |

上述处理仅作用于一次性浏览器中的 DOM/CSS，不改产品源码、服务器数据或工作流连接关系。裁剪范围由所有节点的实际边界加留白确定，完整 11 节点及连接都可见。保留原始布局，没有重新排列成宣传用的虚构链。

用户参照图本身未作为图像附件提供给本次工具，不能断言参照图中的深色区域与本次观察到的占位完全相同。

## 展示与文案

> 从视频帧处理、相机重建到 3D 高斯训练，在同一张画布上组织流程。
>
> 真实界面截图 · 已隐藏设备标识、运行时间及原始影像预览。

单个 img 根据站点最终生效的主题切换文件，支持浅色、深色和跟随系统。图片声明固有尺寸以预留空间。桌面等比铺满原图区域；窄屏仍显示全链，不裁掉节点，点击图片或“查看原图”可打开原尺寸图片缩放查看。当前图是界面展示，不表示训练节点已完成。

## 维护与验收

这是有意保留的静态产品截图，不会随产品版本自动更新。画布组件或流程明显变化时，重新抓取浅/深两张、逐项核查脱敏后一起替换；不应无人审核地抓取在线实验数据并发布。

`npm run build`、13 项同步测试以及 `npm run test:browser` 验证构建、文档和双主题图片。浏览器测试检查实际文件路径、解码尺寸、原图链接、系统主题切换及移动端溢出，生成 `test-results/home-{light,dark}.png` 和 `home-mobile-{light,dark}.png`。
