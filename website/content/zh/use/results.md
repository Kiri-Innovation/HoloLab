# 查看结果

任务完成后，先检查输出，再决定是否继续下游步骤。节点显示完成，表示该次任务完成；是否得到想要的结果，还需要结合数据和算法检查。

## 在画布里预览

展开节点的产物预览，可以查看受支持的数据类型。显示方式取决于输出类型和预览器；没有预览器不等于没有生成文件。

- **尚未运行**：这个节点还没有相应运行结果。
- **产物已被清理**：记录仍在，但文件已通过产物清理操作删除。
- **结果需要更新**或**结果基于旧输入**：当前草稿或上游已经变化，需要检查哪些步骤要重跑。

在可编辑草稿中，部分占位提示提供运行按钮；历史快照是只读视图，需要先返回草稿再运行。

## 日志和历史记录

任务面板的查看日志按钮会打开日志窗口。失败时先看具体错误，再判断是输入、环境还是算法进程的问题。

在运行历史面板选择记录，可以查看当时的快照。快照中的完成状态描述的是那次记录，不能用来判断当前草稿是否已经按新参数运行过。

## 找到文件

产物实际存放在生成它的计算设备上，默认工作空间为 `~/.hololab/node/workspace/`，也可以由设备配置覆盖。

**跳转产物位置需要 Flops Cobrowser 集成。** 普通浏览器不会显示这个入口；在 Cobrowser 中还需要正确配置设备映射。无法跳转时不要据此判断文件不存在，应检查设备配置与产物记录。

目录布局、工作空间迁移和清理规则见[产物与工作空间](../../../docs/artifacts.md)。该参考文档为英文，末尾的未来计划不代表已提供的功能。

## 清理前看影响范围

产物面板可以删除产物。运行历史的右键菜单也提供删除 run 及其产物的操作，确认窗口会先显示预计删除和保留的数量。

仍被其他 run 引用的产物会保留；删除最后一个引用可能删除实际文件。有未结束任务时，删除可能被拒绝，需要先处理任务。不要把删除当成单纯隐藏一条历史记录。

如果手工从文件系统删除产物，记录可能仍存在，预览也可能报找不到文件。更多情况见[排错](troubleshooting.md)。
