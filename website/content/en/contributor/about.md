# About these docs

This section is for people changing HoloLab itself. It describes the system’s design and internals, with architecture and port types as starting points.

To use HoloLab, build workflows or write an algorithm Pack, start with [Learn HoloLab](/docs). Writing a Pack integrates your algorithm; it does not require changing HoloLab’s implementation.

[HoloLab architecture](/docs/build/architecture) explains the responsibilities of the frontend, Gateway and compute nodes, and how they communicate during execution.

[Port type system](/docs/build/type-ir) explains how port declarations, normalized types and runtime observations are represented, and which information determines compatibility.
