# Repeat-4d implementation evidence (2026-11-05)

Implemented `col4d/repeat-4d@0.1.0` in `community_packs/repeat-4d@0.1.0`.
It is a generic colmap4d format utility; no algorithm dependency or frontend
change. Initial git status showed unrelated dirty submodules and reports;
those files were left alone.

## Type findings

No standalone timeless camera leaf existed in the inspected manifests.
`camera_track` in SHARP is a directory bundle, not a leaf camera type.
COLMAP Camera stores intrinsics (model, dimensions, parameters); Image stores
pose (world-to-camera qvec wxyz, tvec), CAMERA_ID and name. `times.bin` maps
IMAGE_ID to signed int64 nanoseconds, with uint64 count and 12-byte records.

New minimal leaf: `colmap-camera`, a scalar JSON file with exactly
`model,width,height,params,qvec,tvec`. The pack README is the cross-session
contract for a future camera array-view provider and interval-pick. Output is
existing scalar `4d_cams: colmap4d-cams`, not a framework camera array.

## Verification

`tests.txt`: **42 passed, 4 subtests passed** (repeat tests plus component port
contract regression). Includes Manifest schema validation; actual prepare
resolver rejects zero/negative/nonfinite duration and FPS; fractional frame
counts and tiny/huge values; invalid intrinsics/poses; rational ties-to-even;
large int64 start timestamps; actual CLI invocation; colmap4d camera/image/time
readers; complete timestamp coverage and strict sidecar validation. Output
contains exactly the four component files with identical calibration/pose,
unique frame names, and empty observations. Input file bytes remain unchanged.

`ports-light.png` / `ports-dark.png`: actual current SnapshotCanvas components
rendering the validated manifest in an isolated fixture. Playwright asserted
camera input and 4d_cams output handles and zero page errors. The visible
"input not ready" state is expected for an unconnected static fixture; these
screenshots do not claim a live dispatched job. Reproduce with:

```sh
node reports/repeat-4d/render-evidence.mjs
```

The script starts and closes its own temporary Vite server on 5198, intercepts
API requests, and writes no frontend source files or online workflows.

## Remaining integration

- The other session must implement/export the `colmap-camera` array-view
  leaves. This pack does not supply that adapter or a camera editor.
- `colmap4d-render-video` is absent; reader/validation interoperability is
  verified instead. No pixels are generated by repeat-4d.
- No live catalog refresh, environment provisioning or job dispatch was
  performed. Running services/jobs were untouched; no service restart,
  registry publication or push.
- Prepare covers individual numeric constraints. Product frame-count and
  final timestamp overflow are execution-entry checks before output writes,
  since there is no pack-specific cross-parameter prepare hook.
